## Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/AmdJhay07-del/personal-portfolio.git
```

Move into the project:

```bash
cd personal-portfolio
```

Open the project in Visual Studio Code:

```bash
code .
```

Open `index.html` directly in a browser or use **Live Server**.

---

## GitHub Codespaces

The project can also be developed completely inside GitHub Codespaces.

The correct Codespaces project directory is:

```text
/workspaces/personal-portfolio
```

From there, the website can be edited, tested, committed, and pushed directly to GitHub.

---

## Git Workflow

A typical development workflow is:

```bash
git status
git add .
git commit -m "Update portfolio"
git push
```

Changes pushed to the `main` branch are deployed through GitHub Pages.
